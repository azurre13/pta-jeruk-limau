Berkas di folder ini disalin tanpa mengubah isinya. Metadata dan checksum disimpan dalam [MANIFEST.json](MANIFEST.json). README indeks dan manifest merupakan berkas pengelolaan sumber, bukan sumber observasi lapangan.

| Folder | Isi dan konteks |
|---|---|
| `template/` | Template asli FTE-CD-1_edited-PBD.docx. Menentukan struktur laporan akademik. |
| `panduan/` | Buku panduan capstone edisi kedua; disahkan 17 Mei 2024. |
| `rubrik-jadwal/` | Jadwal dan rubrik PTA semester ganjil 2026/2027, tiga halaman. |
| `riset/` | Deep research terdahulu. Literatur perlu ditelusuri ke sumber aslinya; konfigurasi alat yang muncul belum merupakan keputusan akhir. |
| `dokumentasi/foto/` | Dua foto parit/tanaman dan kolasenya. Tanggal pemotretan belum dikonfirmasi. |
| `dokumentasi/citra/` | Garis ukur 117,52 m dan 20,54 m. Bukan hasil pengukuran elevasi atau batas bidang lahan. |
| `dokumentasi/lokasi-lain/` | Foto rumah/permukiman. Jangan dipakai untuk menyimpulkan kebun proyek memiliki akses PLN. |
| `dokumentasi/video/` | Video pendek sekitar 19 detik. Pengguna menyatakan video diambil 3 Oktober 2026. Nama file mencantumkan tanggal pengiriman yang berbeda. |
| `dokumentasi/wawancara/` | Transkrip Audio 1 dan Audio 2 yang ditempel pengguna. Berkas audio aslinya belum disertakan. |
